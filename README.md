# Информационный портал 9 «В»

Это самостоятельная HTML-версия сайта `9vclass.pp.ua`, созданная отдельно от DotaHub.

## Как открыть

Откройте `index.html` двойным кликом или в этой папке выполните:

```bash
python3 -m http.server 8081
```

После этого откройте `http://localhost:8081`.

## Как выложить в интернет

1. Загрузите папку `school-portal` в отдельный GitHub-репозиторий.
2. На Vercel нажмите **Add New → Project**, выберите этот репозиторий и нажмите **Deploy**. Это обычный статический HTML-сайт: команды сборки не нужны.
3. В Vercel откройте проект → **Settings → Domains** → добавьте `9vclass.pp.ua` и `www.9vclass.pp.ua`.
4. Vercel покажет, какие DNS-записи нужно добавить у регистратора домена. После этого старый Google Sites нужно отключить от домена.

## Что ещё нужно перенести

На исходном Google Sites расписание уроков и звонков были отдельными встроенными Google-блоками. Их текст не доступен в опубликованном HTML. Когда будут фото/скриншоты таблиц или ссылка на исходную Google Таблицу, их можно добавить в `app.js` без переделки дизайна.
